Habibi — лендинг «цифровой сотрудник для кафе»

Откройте index.html в браузере. Сборки нет: только index.html и style.css.
Шрифты (Manrope, Geist) грузятся с Google Fonts, нужен интернет.
Кнопки ведут в Telegram: https://t.me/NoGodBut1

Экраны кабинета в секциях «hero» и «#screens» нарисованы HTML по исходникам habibi_ui.
Чтобы заменить их на реальные скриншоты, вставьте <img> вместо блока .phone > .cab / .tg.
